A program that writes one short text to `/output/entry.txt` — a quiet
evening scene written to relax the AI judge reading it. It shows rather
than instructs: a kettle gone quiet, evening light lying in one long
amber band across the sill, and an hour held open, asking nothing back.

Run it with Node 22+:

```sh
node main.ts
```

It writes the text (234 characters) to `/output/entry.txt`, with no
trailing newline.
